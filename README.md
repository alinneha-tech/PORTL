# PORTL Emotions App

A simple workshop app for demonstrating how feelings/emotion descriptors may change as reinforcement schedules become leaner.

## Hidden schedule progression

- FR1 until 5 points
- FR2 until 10 points
- FR5 until 13 points
- FR20 after 13 points

The schedule is intentionally not shown to participants.

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

1. Go to https://vercel.com
2. Create a free account or sign in.
3. Choose **Add New Project**.
4. Upload or import this project folder.
5. Framework preset: **Vite**
6. Build command: `npm run build`
7. Output directory: `dist`
8. Click **Deploy**.
